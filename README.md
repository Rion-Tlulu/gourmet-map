# グルメマップ | Gourmet Map

あなたの近くに、おいしい発見。

登録した地点から半径3km以内の飲食店を検索できる、
ログイン不要のグルメ検索Webアプリです。

## 1. 開発目的

職場・学校・駅など、よく利用する地点を登録し、
周辺の店舗を少ない操作で検索できるようにすることを
目的としています。

UI・UX・UD・アクセシビリティを重視して開発しています。

## 2. 主な機能

- 複数地点の登録・編集・削除
- 住所・駅名・GPS・地図・座標による地点登録
- 半径3km以内の店舗検索
- 距離・ジャンル・設備条件による絞り込み
- 店舗一覧・地図表示
- 店舗詳細情報
- 店舗リンク共有
- 検索条件のプリセット
- 外観・アクセシビリティ設定
- JSONバックアップ・復元

お気に入り機能は外部APIの利用条件確認後に提供します。

## 4. セキュリティ

- APIキーをGASのScript Propertiesで管理
- サーバー側の入力検証
- API利用回数制限
- 外部URLの検証
- XSS対策
- Content Security Policy
- 個人情報を含まない運用ログ
- Gitleaksによる機密情報漏洩検査

## 5. データ管理

登録地点、設定、検索条件などは利用者のブラウザ内に
LocalStorageを利用して保存します。

店舗情報は恒久保存しません。

## 9. 注意事項

本アプリはホットペッパーグルメAPIで取得できる
店舗情報を対象としています。

営業時間・定休日・予算などの最新情報については
店舗公式ページ等でご確認ください。

徒歩時間は直線距離から計算した目安です。
